# Environmental CVSS Recalibration

**Engagement:** MediPath Diagnostics (VS-MPD-26-041)
**Method:** Each row starts from Sarah Chen's inherited base CVSS v3.1 score and vector. The environmental score is computed with the FIRST.org CVSS v3.1 formula from a Modified vector (changed only where a specific, evidenced dossier element alters real-world exploitability or exposure) and Security Requirements — Confidentiality (CR), Integrity (IR), Availability (AR) — set from the asset-criticality ratings in `medipath_regulatory_map.md`. A compensating control is only used to lower a metric where the dossier evidences its coverage, enforcement, and bypass-resistance, consistent with the dossier's own control-evaluation rule; a control that is merely mentioned does not change a metric. No finding is retired or merged here — that triage happens in a later task.

## Notes on method and scope

- **Every environmental score above was computed from an explicit Modified vector and Security Requirement set using the FIRST.org CVSS v3.1 formula**, not adjusted by feel. The vector and CR/IR/AR values are shown in each row for traceability and reproducibility in the FIRST.org calculator.
- **Compensating controls were only used to change an exploitability metric where the dossier evidences coverage, enforcement, and bypass-resistance** — the managed mTLS gateway (F-04), the private integration network (F-03), the partner IP allowlist (F-05), and the documented DPO/step-up/dual-approval workflow (F-07). Controls mentioned without that level of evidence (the authorization cache in F-09, the quarterly access review in F-09, MFA/managed workstations in F-02) were not used to change exploitability, since the dossier's control-evaluation rule specifically warns against downgrading a finding solely because a control is mentioned.
- **Health-data and regulatory context raised Security Requirements, and therefore scores, on several findings** (F-01, F-02, F-05, F-06) even where a network-level control also applies, because the underlying data or workflow is rated very-high in the asset-criticality map and the control does not close the specific exploitation path.
- **F-07 was deliberately not driven to zero or retired here.** The environmental score reflects the documented control design as a real, metric-level mitigating factor, but whether every production path actually enforces the ticket and dual-approval requirement — and therefore whether this should ultimately be retired as intended, controlled functionality — is left for the triage task that follows this recalibration.
- **F-08 and F-09 are assessed as materially unchanged rather than forced up or down.** Both cases show that the available context includes offsetting factors, or no evidenced change to the attack path at all — the recalibration follows the evidence on a per-finding basis rather than applying a uniform directional shift.
- No findings were removed, collapsed, or bypassed in this task. All ten findings from `sarahs_raw_findings.md` are scored individually above; retirement and merger decisions are addressed in the subsequent findings-triage task.
