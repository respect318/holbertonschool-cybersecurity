# Environmental CVSS Recalibration

**Engagement:** MediPath Diagnostics (VS-MPD-26-041)
**Method:** Each row starts from Sarah Chen's inherited base CVSS v3.1 vector and score, then recomputes an environmental score using the FIRST.org CVSS v3.1 methodology: Modified Base Metrics where the client-context dossier evidences a real change to exploitability, and Security Requirements (Confidentiality/Integrity/Availability) set from the asset-criticality map in `medipath_regulatory_map.md`. A rise or fall in score is only accepted where a specific, evidenced dossier element drives it — a compensating control mentioned without evidenced coverage, enforcement, and bypass-resistance is not applied as a reduction, per the dossier's own control-evaluation rule.

## Notes on method and scope

- **Compensating controls were only applied as reductions where the dossier evidences coverage, enforcement, and bypass-resistance** (F-04's mTLS gateway, F-07's DPO/step-up/dual-approval workflow, F-08's SSO/MFA rollout), consistent with the dossier's control-evaluation rule. Controls that are merely mentioned without that evidence (e.g., the authorization cache in F-03/F-09, the source-IP allowlist in F-05) were not used to lower a score.
- **Health-data and regulatory context pushed several scores up** (F-01, F-03, F-05, F-06, F-09) even where a compensating control exists, because the asset-criticality map rates the underlying data or workflow very-high and the control does not address the specific exploitation path.
- **F-07 was deliberately not driven to zero or retired here.** The environmental score reflects the documented control design as a real mitigating factor, but confirming that every production path enforces the ticket and dual-approval requirement — and therefore whether this should ultimately be retired as intended functionality — is left for the triage stage that follows this recalibration.
- No findings were merged or connected into attack chains in this task; F-03/F-09's shared identity-governance texture and F-01/F-10's potential data-path relationship are flagged for later consolidation review, not resolved here.
