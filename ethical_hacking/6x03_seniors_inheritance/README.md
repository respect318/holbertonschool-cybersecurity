# The Senior's Inheritance | Penetration Testing Engagement

## Project Overview
This project simulates a real-world consulting scenario where a raw technical pentest report must be recalibrated and translated into an audit committee-ready deliverable. Taking over a client engagement (MediPath Diagnostics) in a colleague's absence, the objective is to ensure that severity scores, root causes, and business impacts are accurately framed for executive stakeholders.

## Learning Objectives & Scope
- **CVSS Calibration:** Recalibrating base CVSS v3.1 scores against environmental and regulatory contexts (RGPD Article 9, HDS compliance).
- **Triage & Merger:** Identifying duplicates, retiring irrelevant findings, and surfacing complex attack chains.
- **Stakeholder Communication:** Producing a layered deliverable suitable for a non-technical CEO, a regulatory-focused DPO, a technical director, and a board observer.
- **Consultant Posture:** Tracing modifications to a colleague's work professionally and accurately.

## Repository Structure
├── README.md                  # Project documentation & overview
├── executive_summary.md       # C-level executive summary without technical jargon
└── full_report.md             # Detailed findings and recalibrated assessment


## Requirements & Standards
- All deliverables are written in professional, audience-appropriate Markdown.
- Severities modified from the original draft are traced with neutral, technical justifications.
- Executive summaries contain zero technical jargon, translating vulnerabilities directly into business and regulatory risks.
